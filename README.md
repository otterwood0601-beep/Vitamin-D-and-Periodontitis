# Vitamin D and Periodontitis

Analysis and visualization code for a study of vitamin D and periodontitis, with a focus on GDF15, ERK1/2 signaling, gingival fibroblasts, and extracellular matrix remodeling.

## Repository Contents

`Code.zip` contains scripts organized by analytical method:

- Survey-weighted regression, subgroup analysis, and restricted cubic splines.
- Machine learning, LASSO feature selection, model evaluation, and SHAP analysis.
- Summary-data-based Mendelian randomization (SMR), HEIDI testing, and two-sample Mendelian randomization.
- Bulk RNA-seq differential expression analysis.
- Single-cell clustering, cell annotation, and phenotype-associated cell identification using Scissor.
- WGCNA, hdWGCNA, and SCENIC regulatory network analysis.
- Functional enrichment, interaction networks, and pathway activity analysis.
- Virtual gene knockout and overexpression analysis.
- Cell composition deconvolution, spatial transcriptomics, and pseudotime analysis.
- Disease–vitamin D expression signature comparison.
- Data preparation, shared configuration, and figure generation.

## Software

The scripts primarily use R and Python. Additional PowerShell, JavaScript, and shell scripts support selected workflows.

Required packages are specified by the imports and library calls in each script.

## Usage

1. Download and extract `Code.zip`.
2. Select the folder corresponding to the analysis of interest.
3. Install the required software and packages.
4. Update input and output paths for the local computing environment.
5. Prepare the required input data before running the analysis and figure-generation scripts.

Some scripts retain paths from the original computing environment and require modification before execution.

## Data Availability

Input datasets are not included in the code archive. Data sources and accession numbers should be consulted in the associated manuscript and supplementary materials.
